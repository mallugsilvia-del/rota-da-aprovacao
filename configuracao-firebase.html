Como conectar o Rota da Aprovação ao Firebase

Você fará esta configuração uma única vez. Depois, novas questões poderão ser cadastradas pelo painel Admin do próprio site.

  1. Crie o projeto.Acesse o Console do Firebase, crie um projeto e adicione um aplicativo do tipo Web.
  2. Ative o Firestore.Abra “Firestore Database”, crie o banco em modo de produção e escolha uma região.
  3. Ative o login.Em “Authentication → Sign-in method”, habilite “Google” (recomendado) ou “E-mail/senha”.
  4. Configure o site.Copie o objeto firebaseConfig do Console e substitua os valores no arquivo firebase-config.js.
  5. Publique as regras.Copie todo o conteúdo de firestore.rules para “Firestore → Regras” e clique em publicar.
  6. Autorize seu usuário.Copie o UID exibido em Authentication. No Firestore, crie a coleção admins e um documento cujo ID seja exatamente esse UID. Adicione o campo ativo com valor booleano true.
  7. Abra o painel Admin.Entre com a conta autorizada. No painel Admin, use “Carregar banco completo do projeto” e depois “Importar JSON no Firestore”.

Onde o site pode ser publicado?

Como é um site estático, você pode usar Firebase Hosting, GitHub Pages ou outro serviço que entregue arquivos HTML, CSS e JavaScript. O computador da escola não precisa ter Node.js para acessar e usar o site já publicado.

Estrutura de cada questão

O banco guarda vestibular, ano, número, matéria, tema, dificuldade, enunciado, alternativas, resposta, dica, etapas da resolução, explicação final, recomendação, fonte e estado de publicação.

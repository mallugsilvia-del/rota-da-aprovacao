Como conectar o Rota da Aprovação ao Firebase

Você fará esta configuração uma única vez. Depois, estudantes poderão criar contas e sincronizar o histórico, enquanto administradores autorizados gerenciam as questões.

  1. Crie o projeto.Acesse o Console do Firebase, crie um projeto e adicione um aplicativo do tipo Web.
  2. Ative o Firestore.Abra “Firestore Database”, crie o banco em modo de produção e escolha uma região.
  3. Ative o login.Em “Authentication → Sign-in method”, habilite “E-mail/senha”. Se desejar, habilite também o Google.
  4. Autorize o domínio.Em “Authentication → Settings → Authorized domains”, inclua o domínio publicado, como usuario.github.io.
  5. Configure o site.Copie o objeto firebaseConfig do Console e substitua os valores no arquivo firebase-config.js.
  6. Publique as regras.Copie todo o conteúdo de firestore.rules para “Firestore → Regras” e clique em publicar.
  7. Autorize seu administrador.Crie primeiro a conta no Authentication, copie o UID exibido e, no Firestore, crie a coleção admins com um documento cujo ID seja exatamente esse UID. Adicione o campo ativo com valor booleano true.
  8. Abra o painel Admin.Entre com a conta autorizada. No painel Admin, use “Carregar banco completo do projeto” e depois “Importar JSON no Firestore”.

Onde o site pode ser publicado?

Como é um site estático, você pode usar Firebase Hosting, GitHub Pages ou outro serviço que entregue arquivos HTML, CSS e JavaScript. O computador da escola não precisa ter Node.js para acessar e usar o site já publicado.

Estrutura de cada questão

O banco guarda vestibular, ano, número, matéria, tema, dificuldade, enunciado, alternativas, resposta, dica, etapas da resolução, explicação final, recomendação, fonte, imagem original e estado de publicação.

Quando o login disser “e-mail ou senha inválidos”

Um registro em admins/{UID} não cria a conta de acesso. Crie a conta primeiro, use “Esqueci minha senha” se ela já existir e confira se E-mail/senha está habilitado. Estudantes comuns não precisam de documento em admins.
